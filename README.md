# ipad-dashboard

Dashboard d'affichage permanent pour un vieil iPad (Safari iOS 12) : heure, météo, compte à rebours, newsletter.

- `index.html` : la page (JavaScript volontairement simple pour rester compatible avec iOS 12)
- `newsletter.json` : contenu de la newsletter affichée (`{ "title": "...", "items": [ { "title": "...", "source": "..." } ] }`)
